# FreeUni-Design-Patterns

Assignments and projects for the **Software Design and Architecture** course at **Free University of Tbilisi**, focusing on clean object-oriented design, Gang of Four (GoF) design patterns, SOLID principles, strict static type checking, and unit testing in Python.

## Repository Structure

```text
├── assignment-1-spore/      # Predator–prey evolution & chase simulation
│   ├── core/                # Domain models, strategies, decorators, builders, factories, observers
│   ├── runner/              # Simulation entry point
│   ├── tests/               # Pytest unit & integration test suite
│   └── pyproject.toml       # Ruff, Mypy, and Pytest configuration
└── ...                      # Upcoming course assignments
